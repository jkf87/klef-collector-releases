# KLEF 공람문서 요약

공개 배포·설치 안내 저장소입니다. 현재 버전은 **1.8.3**입니다([변경 사항](RELEASE-v1.8.3.md) · [1.8.2](RELEASE-v1.8.2.md) · [1.8.1](RELEASE-v1.8.1.md) · [1.8.0](RELEASE-v1.8.0.md) · [1.7.0](RELEASE-v1.7.0.md) · [1.6.3](RELEASE-v1.6.3.md) · [1.6.2](RELEASE-v1.6.2.md) · [1.6.1](RELEASE-v1.6.1.md)). 기존 개발 저장소와 Git 이력은 이 저장소에 포함하지 않습니다. 배포 ZIP에는 실행에 필요한 코드가 포함됩니다.

**[설치 안내 페이지](https://jkf87.github.io/klef-collector-releases/)** · [최신 다운로드](https://github.com/jkf87/klef-collector-releases/releases/latest) · [개인정보처리방침](docs/PRIVACY.md) · [Chrome 웹 스토어 등록 준비](docs/CHROME-WEB-STORE.md) · [지원](https://github.com/jkf87/klef-collector-releases/issues)

## 무엇을 하는 도구인가요?

접근권한이 있는 공문을 정상 파일저장 기능으로 받은 뒤, 로컬 도우미가 요약하여 Chrome의 공람 목록에 핵심 내용·조치·기한·대상을 표시합니다. 일반 웹페이지에서 선택한 본문도 우클릭으로 요약할 수 있습니다.

기본은 Qwen3.5 2B CPU 로컬 모델입니다. LFM2.5 230M/1.2B, 공문 요약 전용으로 학습한 KLEF Qwen3.5 0.8B(실험), 실험적인 Chrome 내장 AI, 사용자가 지정하고 전송에 동의한 외부 API도 공문 요약 옵션으로 제공합니다. 선택 본문 요약은 로컬 모드만 지원합니다. 정확성을 보장하지 않으므로 중요한 판단에는 원문을 확인하세요. 기관이나 Google의 공식 제품이 아니며 DRM 해제나 접근권한 우회 기능은 없습니다.

## Windows 설치

Node.js를 미리 설치하지 않아도 됩니다. 관리자 권한도 필요 없습니다. [설치 안내 페이지](https://jkf87.github.io/klef-collector-releases/)에 같은 순서가 그림과 함께 있습니다.

1. Chrome 웹 스토어에서 **KLEF 공람문서 요약** 확장을 추가합니다. 현재 심사 중이라 승인 전에는 아래 [ZIP으로 설치](#zip으로-설치)를 따르세요.
2. Releases에서 **`klef-helper-setup.exe`를 받아 실행**합니다. 서명하지 않은 파일이라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 사용자 폴더(`%LOCALAPPDATA%\KLEF-Helper`)에 도우미를 풀고 Node.js 준비, 필요한 파일 설치(약 80MB, Node.js가 없으면 약 35MB 더), Chrome 확장 연결을 한 번에 합니다.
3. 확장 AI 설정에서 **로컬 모델 → 이 모델 준비하기**를 진행합니다. 모델은 별도 다운로드이며 인터넷·디스크·RAM이 필요합니다. Ollama·Python·GPU는 필수가 아닙니다.

설치가 끝나면 웹 스토어 판 확장이 필요할 때 도우미를 알아서 켭니다. `시작.cmd`를 켜 둘 필요가 없습니다.

### ZIP으로 설치

설치 파일 실행이 막힌 PC나 웹 스토어 승인 전에 씁니다.

1. Releases에서 **`klef-worker-1.8.3.zip` 전체를 내려받아 압축 해제**합니다. `Source code.zip`은 설치 파일이 아닙니다.
2. 압축 푼 폴더 맨 위의 **`설치.cmd`를 더블클릭**합니다. 이 PC의 Node.js를 찾고, 없거나 22.15.0보다 낮으면 공식 배포본을 폴더 안 `.node`에 받아 씁니다. 받은 파일은 공식 해시로 확인하며 시스템에는 설치하지 않습니다. 마지막에 웹 스토어 판 확장 자동 실행도 등록합니다.
3. 웹 스토어 확장을 쓸 수 없으면 `chrome://extensions`의 개발자 모드에서 **압축해제된 확장 프로그램을 로드**하고 워커 안의 `extension` 폴더를 선택합니다. 기관이 개발자 모드를 제한했다면 우회하지 말고 관리자에게 문의하세요. 이 경우 **`시작.cmd`를 더블클릭**해 도우미를 켜 두거나, 확장 설정에 나오는 등록 명령을 한 번 실행합니다.
4. 확장 AI 설정에서 **이 모델 준비하기**를 진행합니다.

기본 Qwen은 약 1.40GB, 경량 LFM 230M은 약 247MB, LFM 1.2B는 약 731MB, KLEF 0.8B는 약 542MB의 모델 다운로드가 필요합니다. 실행 RAM은 다운로드 크기와 다릅니다. Windows x64, CPU 환경을 지원하며 Apple Silicon Mac은 Node.js 22.15.0 이상을 설치한 뒤 워커 폴더에서 `npm ci --omit=optional`, `npm start`로 실행합니다. 공람 네이티브 저장 자동화는 Windows 전용입니다.

**확장만 설치하면 로컬 도우미는 실행되지 않습니다.** 도우미 설치 파일이나 ZIP을 함께 설치하세요. 연결 안내가 계속 뜨면 시작 메뉴의 **KLEF 도우미 직접 켜기**(ZIP 설치는 `시작.cmd`) 창의 오류와 `http://127.0.0.1:7654/health`를 확인하세요.

## 공문 저장 폴더

공문은 기본으로 `다운로드\KLEF`에 저장됩니다. 파일저장 창이 다른 폴더를 기억하고 있어도 저장할 때마다 이 폴더로 되돌립니다. 저장 폴더는 AI 설정의 **공문 저장 폴더**에서 `다운로드` 안의 다른 폴더로 바꿀 수 있습니다.

비전자문서와 접수 전 유통문서는 본문 파일이 없어 KLEF가 파일저장을 지원하지 않습니다. 이런 문서는 건너뛰고 나머지를 처리하며, 요약할 수 없습니다.

## 사용

공람 목록에서 문서를 체크하고 패널의 **요약하기**를 누르면 파일저장과 요약이 이어서 진행됩니다. 체크하지 않고 **요약 없는 문서 모두 요약**을 두 번 누르면 지금 화면에서 요약이 없는 문서를 모두 처리합니다. 첫 번째 누름은 몇 건인지만 알려 주고, 저장 중에는 같은 버튼으로 멈출 수 있습니다.

저장 창이 작업을 가린다면 AI 설정의 **공문 저장 폴더 → 저장 창을 화면 밖에서 처리합니다 (실험)**을 켜세요. 저장 창을 모니터 바깥으로 옮겨 처리하고, 실패하면 화면 가운데로 다시 꺼냅니다. KLEF 저장 프로그램을 건너뛰고 파일을 직접 받지는 않습니다. 저장이 "도우미가 그 창을 찾아 누르지 못했습니다"로 실패하면 도우미를 껐다가 다시 켠 뒤 다시 실행하세요.

새 공문이 목록에 올라왔다고 저절로 요약되지는 않습니다. 자동 요약은 저장 폴더에 새로 생긴 공문 파일을 요약하는 기능이고, 파일은 KLEF 파일저장 창으로 받아야 하기 때문입니다.

## 업데이트

**설치 파일로 설치했다면** 진행 중인 작업이 끝난 뒤 새 `klef-helper-setup.exe`를 실행합니다. 켜져 있는 도우미를 먼저 끄고 파일을 바꾸며, 요약 기록·설정·받은 모델은 그대로 둡니다. 그다음 Chrome 확장과 사용 페이지를 새로고침합니다.

**ZIP으로 설치했다면** 기존 도우미를 종료하고 기존 워커 폴더의 코드만 업데이트하며 **`summaries.json`, `.native-save-ledger.json`, `.cache`를 보존**하세요. `설치.cmd`를 실행한 뒤 Chrome 확장과 사용 페이지를 새로고침합니다. 확장이 도우미를 자동으로 켜 둔 상태라면 AI 설정의 **도우미 자동 실행 → 도우미 중지**를 한 번 누르거나 PC를 다시 시작해야 새 도우미가 뜹니다. 다른 폴더로 이동하면 기존 데이터 경로와 확장 ID가 달라질 수 있습니다. ZIP 폴더의 기록은 설치 파일 위치로 자동으로 옮겨지지 않습니다.

**제거:** 설치 파일로 설치했다면 Windows 설정 → 앱에서 **KLEF 공람문서 요약 도우미**를 제거합니다. 설치 폴더 전체(받은 모델·요약 기록 포함)와 자동 실행 등록을 지우고, `다운로드\KLEF`의 공문 저장본은 남깁니다.

## 배포 파일과 검증

- `klef-helper-setup.exe`: Windows 도우미 설치 파일. 사용자 폴더에 설치하며 관리자 권한이 필요 없습니다. 파일 이름에 버전을 넣지 않아 [최신판 바로 받기](https://github.com/jkf87/klef-collector-releases/releases/latest/download/klef-helper-setup.exe) 링크가 늘 최신판을 가리킵니다.
- `klef-worker-1.8.3.zip`: 도우미·확장·Windows 설치/실행 스크립트·사용 설명.
- `klef-extension-1.8.3.zip`: 확장 파일만. 도우미는 포함하지 않습니다.
- `SHA256SUMS.txt`: 다운로드 무결성 확인용 해시.

공문·요약·API 키·설정·개인 경로·모델 캐시와 개발 Git 이력은 배포하지 않습니다. 시험용 문서 식별자는 가상 이름으로 정리했습니다. 1.8.3은 배포 전 검사와 자동 테스트 221개를 통과했고, 실제 K-에듀파인에서 여러 건 일괄 요약으로 저장 속도와 첨부 누락이 없는지 확인했습니다([자세히](RELEASE-v1.8.3.md#확인)). 모든 환경의 동작이나 요약 품질을 보장하는 수치는 아닙니다.

## Chrome 웹 스토어 상태

**웹 스토어에 제출해 심사를 기다리고 있습니다(링크가 있는 사람만 볼 수 있는 미등록 공개).** 승인되면 설치 안내 페이지의 [Chrome 웹 스토어 열기]가 바로 열립니다. 웹 스토어 판 확장 ID는 `cebakkjjpinapjoplgkbekmcopoimpdf`이고, 1.8.2부터 도우미는 이 ID로 자동 실행을 등록합니다. 등록 절차와 권한별 설명은 [등록 준비 문서](docs/CHROME-WEB-STORE.md)를 참고하세요.

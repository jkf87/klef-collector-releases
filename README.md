# KLEF 공람문서 요약

공개 배포·설치 안내 저장소입니다. 현재 버전은 **1.6.3**입니다([변경 사항](RELEASE-v1.6.3.md) · [1.6.2](RELEASE-v1.6.2.md) · [1.6.1](RELEASE-v1.6.1.md)). 기존 개발 저장소와 Git 이력은 이 저장소에 포함하지 않습니다. 배포 ZIP에는 실행에 필요한 코드가 포함됩니다.

[최신 다운로드](https://github.com/jkf87/klef-collector-releases/releases/latest) · [개인정보처리방침](docs/PRIVACY.md) · [Chrome 웹 스토어 등록 준비](docs/CHROME-WEB-STORE.md) · [지원](https://github.com/jkf87/klef-collector-releases/issues)

## 무엇을 하는 도구인가요?

접근권한이 있는 공문을 정상 파일저장 기능으로 받은 뒤, 로컬 도우미가 요약하여 Chrome의 공람 목록에 핵심 내용·조치·기한·대상을 표시합니다. 일반 웹페이지에서 선택한 본문도 우클릭으로 요약할 수 있습니다.

기본은 Qwen3.5 2B CPU 로컬 모델입니다. LFM2.5 230M/1.2B, 실험적인 Chrome 내장 AI, 사용자가 지정하고 전송에 동의한 외부 API도 공문 요약 옵션으로 제공합니다. 선택 본문 요약은 로컬 모드만 지원합니다. 정확성을 보장하지 않으므로 중요한 판단에는 원문을 확인하세요. 기관이나 Google의 공식 제품이 아니며 DRM 해제나 접근권한 우회 기능은 없습니다.

## Windows 설치

Node.js를 미리 설치하지 않아도 됩니다. 관리자 권한도 필요 없습니다.

1. Releases에서 **`klef-worker-1.6.3.zip` 전체를 내려받아 압축 해제**합니다. `Source code.zip`은 설치 파일이 아닙니다.
2. 압축 푼 폴더 맨 위의 **`설치.cmd`를 더블클릭**합니다. 이 PC의 Node.js를 찾고, 없거나 22.15.0보다 낮으면 공식 배포본을 폴더 안 `.node`에 받아 씁니다. 받은 파일은 공식 해시로 확인하며 시스템에는 설치하지 않습니다. 기본 설치는 약 80MB입니다.
3. **`시작.cmd`를 더블클릭**하고 실행 창을 열어 둡니다. 이 창을 닫으면 도우미도 꺼집니다.
4. 현재는 Chrome 웹 스토어 등록 전입니다. `chrome://extensions`의 개발자 모드에서 **압축해제된 확장 프로그램을 로드**하고 워커 안의 `extension` 폴더를 선택합니다. 기관이 개발자 모드를 제한했다면 우회하지 말고 관리자에게 문의하세요.
5. 확장 AI 설정에서 **로컬 모델 → 이 모델 준비하기**를 진행합니다. 모델은 별도 다운로드이며 인터넷·디스크·RAM이 필요합니다. Ollama·Python·GPU는 필수가 아닙니다.

기본 Qwen은 약 1.40GB, 경량 LFM 230M은 약 247MB, LFM 1.2B는 약 731MB의 모델 다운로드가 필요합니다. 실행 RAM은 다운로드 크기와 다릅니다. Windows x64, CPU 환경을 지원하며 Apple Silicon Mac은 Node.js 22.15.0 이상을 설치한 뒤 워커 폴더에서 `npm ci --omit=optional`, `npm start`로 실행합니다. 공람 네이티브 저장 자동화는 Windows 전용입니다.

**확장 ZIP만 설치하면 로컬 도우미는 실행되지 않습니다.** 연결 안내가 계속 뜨면 `시작.cmd` 창의 오류와 `http://127.0.0.1:7654/health`를 확인하세요.

## 공문 저장 폴더

공문은 기본으로 `다운로드\KLEF`에 저장됩니다. 파일저장 창이 다른 폴더를 기억하고 있어도 저장할 때마다 이 폴더로 되돌립니다. 저장 폴더는 AI 설정의 **공문 저장 폴더**에서 `다운로드` 안의 다른 폴더로 바꿀 수 있습니다.

비전자문서와 접수 전 유통문서는 본문 파일이 없어 KLEF가 파일저장을 지원하지 않습니다. 이런 문서는 건너뛰고 나머지를 처리하며, 요약할 수 없습니다.

## 사용

공람 목록에서 문서를 체크하고 패널의 **요약하기**를 누르면 파일저장과 요약이 이어서 진행됩니다. 체크하지 않고 **요약 없는 문서 모두 요약**을 두 번 누르면 지금 화면에서 요약이 없는 문서를 모두 처리합니다. 첫 번째 누름은 몇 건인지만 알려 주고, 저장 중에는 같은 버튼으로 멈출 수 있습니다.

새 공문이 목록에 올라왔다고 저절로 요약되지는 않습니다. 자동 요약은 저장 폴더에 새로 생긴 공문 파일을 요약하는 기능이고, 파일은 KLEF 파일저장 창으로 받아야 하기 때문입니다.

## 업데이트

진행 중인 작업이 끝난 뒤 기존 도우미를 종료합니다. 기존 워커 폴더의 코드만 업데이트하고 **`summaries.json`, `.native-save-ledger.json`, `.cache`를 보존**하세요. `설치.cmd`와 `시작.cmd`를 차례로 실행한 뒤 Chrome 확장과 사용 페이지를 새로고침합니다. 확장이 도우미를 자동으로 켜 둔 상태라면 AI 설정의 **도우미 자동 실행 → 도우미 중지**를 한 번 누르거나 PC를 다시 시작해야 새 도우미가 뜹니다. 다른 폴더로 이동하면 기존 데이터 경로와 확장 ID가 달라질 수 있습니다.

## 배포 파일과 검증

- `klef-worker-1.6.3.zip`: 도우미·확장·Windows 설치/실행 스크립트·사용 설명.
- `klef-extension-1.6.3.zip`: 확장 파일만. 도우미는 포함하지 않습니다.
- `SHA256SUMS.txt`: 다운로드 무결성 확인용 해시.

공문·요약·API 키·설정·개인 경로·모델 캐시와 개발 Git 이력은 배포하지 않습니다. 시험용 문서 식별자는 가상 이름으로 정리했습니다. 1.6.3은 Windows에서 자동 테스트 200개와 배포 전 검사를 통과했습니다. 모든 환경의 동작이나 요약 품질을 보장하는 수치는 아닙니다.

## Chrome 웹 스토어 상태

**아직 웹 스토어에 등록되거나 승인되지 않았습니다.** 현재 ZIP은 GitHub 설치용입니다. 제출 전 아이콘·스크린샷·홍보 이미지와 심사 안내를 준비해야 합니다. 로컬 도우미가 필요한 구조도 스토어에 명확히 공개해야 합니다. 자세한 절차와 권한별 설명은 [등록 준비 문서](docs/CHROME-WEB-STORE.md)를 참고하세요.

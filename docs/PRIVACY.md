# KLEF 공람문서 요약 개인정보처리방침

적용 버전: 1.2.3 · 시행일: 2026-09-14 · 배포자: GitHub 계정 jkf87

이 확장과 로컬 도우미는 사용자가 접근권한을 가진 공문 또는 사용자가 선택한 웹페이지 본문을 요약하는 도구입니다. 기관 및 Google의 공식 제품이 아닙니다.

## 처리하는 데이터와 목적

- 공문: 목록의 제목·문서번호 등 표시 정보, 정상 저장 기능으로 받은 본문·첨부, 요약 결과·조치·기한·대상. 공문을 연결하고 요약을 표시하며 완료 기록을 재사용하는 데 씁니다. 본문에 이름이나 연락처 등 개인정보가 있다면 요약 처리에 포함될 수 있습니다.
- 선택 본문: 사용자가 우클릭으로 요약을 요청한 텍스트와 요약 결과. 전체 페이지나 방문 이력을 수집하는 기능은 없습니다. 해당 탭 URL·문서 ID·임시 토큰은 메시지를 원래 탭에만 전달하기 위해 Chrome 세션 저장소에 임시 보관합니다. 선택 본문 요약 요청에는 URL·페이지 제목을 보내지 않습니다.
- 설정: 선택 엔진·모델, CPU 옵션, 외부 API 주소·모델명·사용자가 입력한 API 키와 전송 동의 상태. API 키는 Windows 로컬 도우미에서 DPAPI로 암호화하여 보관하며 확장 저장소에는 보관하지 않습니다.
- 진단: 문서번호, 엔진·모델명, 처리 시각·구간·토큰 수·소요시간·오류 코드 등. 로컬 진단 로그에는 공문 본문·모델 응답·API 키를 기록하지 않습니다. 실행 콘솔에는 로컬 파일 경로나 오류 정보가 포함될 수 있습니다.

## 어디에서 처리하는가

기본 모드는 같은 PC의 로컬 CPU 모델입니다. 확장과 도우미는 `127.0.0.1:7654`의 로컬 연결로 통신합니다. 개발자가 운영하는 수집 서버로 공문·선택 본문·요약을 자동 전송하는 기능, 광고 및 이용 분석 추적 기능은 없습니다.

선택 본문 요약은 로컬 모드만 지원합니다. 공문 요약은 다음 선택 기능을 제공합니다.

- 외부 API: 사용자가 API 모드를 고르고 서버를 지정하여 전송에 동의한 경우에만, 공문 본문·첨부에서 추출한 텍스트와 요약 요청을 그 서버로 보냅니다. 원격 서버에는 HTTPS를 사용합니다. 해당 제공자의 보관·학습·삭제 정책과 사용료는 제공자마다 다르므로 사용자가 확인해야 합니다. 개발자가 제공자 측 무보관 또는 학습 제외를 보장하지 않습니다. 실패해도 다른 업체나 API로 자동 전환하지 않습니다.
- Chrome 내장 AI: 사용자가 선택하고 준비한 경우 Chrome이 관리하는 온디바이스 모델을 사용합니다. 모델 설치와 브라우저 기능은 Google의 조건에 따릅니다. 개발자의 외부 요약 서버로 전송하는 방식은 아닙니다.
- 다운로드: 최초 의존성 설치는 npm, 모델·실행기 다운로드는 GitHub·Hugging Face 등의 배포 서버를 사용합니다. 이 서버에는 다운로드 과정의 IP 주소·요청 정보가 전달될 수 있습니다. 다운로드 요청에 공문·요약을 첨부하지 않습니다. 관련 서비스 자체의 개인정보 정책이 적용됩니다.

## 저장과 삭제

공문 저장본, `summaries.json`, `.native-save-ledger.json`, `.cache`의 설정·모델·진단 자료는 사용자 PC에 남으며 자동 전체 삭제하지 않습니다. 확장은 Chrome 로컬 저장소에도 요약을 캐시합니다. 문서와 요약 캐시 전체를 앱 자체에서 암호화하지는 않으므로 공유 PC의 계정·파일 접근권한을 관리하세요.

선택 본문 작업은 도우미 메모리에서 처리하며 공문 요약 파일에 영구 저장하지 않습니다. 완료·실패 결과는 기본 5분, 처리 중 작업은 최대 30분의 만료 기준으로 정리합니다. 확장 세션 정보는 탭 이동·닫기·새 요약 요청 시 정리하며 만료된 토큰 요청은 거부합니다.

삭제하려면 진행 중인 작업을 종료한 뒤 필요한 데이터만 백업하고, 저장본·요약·장부·설정·로그를 직접 삭제하세요. API 키는 AI 설정에서 삭제할 수 있습니다. 확장을 제거하면 그 확장의 저장소는 정리되지만 로컬 도우미 파일과 다운로드한 모델은 남습니다. 도우미를 다시 연결하면 로컬 요약이 다시 캐시될 수 있습니다. 외부 API에 이미 전달한 데이터의 삭제는 해당 제공자에게 문의해야 합니다.

## 사용 제한과 문의

처리한 정보는 사용자가 요청한 요약, 표시, 재시도 및 설정 관리에 사용합니다. 개발자는 이를 판매하거나 광고·신용평가 목적으로 사용하지 않습니다. 정보 사용은 Chrome Web Store User Data Policy의 Limited Use 요구사항을 준수합니다.

기관 규정상 외부 전송이 금지된 문서는 API 모드로 보내지 마세요. 개인정보나 비공개 문서를 공개 GitHub Issues에 올리지 마세요. 문의는 [지원 페이지](https://github.com/jkf87/klef-collector-releases/issues)에 개인정보를 제거한 증상·버전·오류 코드로 남길 수 있습니다. GitHub에 직접 올린 정보에는 GitHub의 공개 범위와 정책이 적용됩니다.

데이터 처리 방식이 바뀌면 이 문서의 적용 버전과 시행일을 갱신합니다.
